# Autocomplete
The goal of this project is to implement an autocomplete feature. Given a set of strings (like words or phrases) and associated non-negative weights, the feature should be able to take a prefix typed by the user and list all the strings in the set that start with that prefix. The listing should be presented in descending order based on the weights.   

Autocomplete is a significant feature in many modern applications. As a user types, the application predicts the complete query they intend to enter. It's particularly effective when dealing with a limited number of likely queries. Examples include the Internet Movie Database suggesting movie titles, search engines offering query suggestions, and cell phones speeding up text input. The weights used to rank suggestions are typically determined by historical data, like movie revenues, search query frequencies, or user typing history. For this specific assignment, a predefined set of all possible queries and their associated weights is provided.   

The performance of autocomplete is critical, especially in systems like search engines where suggestions need to be returned within milliseconds (around 50ms) to be useful. This computation ideally happens with every keystroke for every user.
